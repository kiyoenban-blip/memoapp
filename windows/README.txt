QuickNote Windows 자동 실행

1. ZIP 전체를 폴더에 압축 해제합니다.
2. Install.cmd를 더블 클릭합니다. 관리자 권한은 필요 없습니다.
3. 메모 창이 열립니다. 다음 Windows 로그인부터 자동으로 열립니다.

Windows 10/11, Microsoft Edge 및 기본 Windows PowerShell 5.1이 필요합니다.
설치 시 Windows의 C# 컴파일러로 작은 실행 파일을 만듭니다.
Node.js, npm, 개발 서버, 인터넷 연결은 실행 시 필요하지 않습니다.
설치 위치: %LOCALAPPDATA%\QuickNote
자동 실행 위치: 현재 사용자의 시작프로그램 폴더의 QuickNote.lnk
해제: Disable-Autostart.cmd 실행. 메모나 바탕화면 바로가기는 삭제하지 않습니다.
다시 켜기/업데이트: Install.cmd 재실행.

로컬 전용 메모를 먼저 열고, 메모가 없으면 빈 메모 한 개를 만듭니다.
메모는 Edge 기본 프로필의 http://localhost:43827 저장소에 보관됩니다.
기존 웹사이트/다른 포트/다른 브라우저의 메모는 자동 이전되지 않습니다.
프로필 또는 사이트 데이터를 삭제하면 동기화하지 않은 메모가 지워집니다.
창을 닫아도 작은 로컬 호스트가 로그아웃까지 실행됩니다.
호스트는 이 PC의 loopback에서만 수신합니다. 외부 기기 접속은 받지 않습니다.
포트 43827을 다른 프로그램이 사용 중이면 충돌 오류가 발생할 수 있습니다.
보안 정책이 스크립트/컴파일된 실행 파일을 차단하면 관리자에게 문의하세요.
실제 Windows 로그인 자동 실행은 Linux 개발 환경에서 검증하지 못했습니다.
